## 7. 已知限制

1. **无 UDP 代理**：内核缺 `nft_tproxy`，`enable_udp_proxy=0`；IPv4 UDP 不代理（QUIC 443 由 nft 拦），IPv6 UDP 由 guard fail-closed。UDP 游戏/语音可能走 IPv4 直连或失败。
2. **Reality 已移除**：当前主固定出口是 3x-ui 新建的 VLESS TCP+TLS:8443；Hy2 备用；Reality 节点已从 OpenClash 配置删除，3x-ui id 2 入站保留给其他客户端，不再出现在 OpenClash 分组。
3. **乌龟订阅 403**：需机场后台解锁；解锁后 provider 自动恢复。
4. **`2001:2::/64` 是 Fake-IP6**：不要把它当作可路由地址；不要加 `IP-CIDR6,2001:2::/64,DIRECT`。
5. **`inet ipv6_cn` 是 ssr-plus 遗留表**：本次保留；重启后若消失，`openclash_v6_guard` 仍提供 fail-closed。
6. **Ruby 启动告警**：`Config File params checked Failed,【Out of memory - ls -l /sys/class/net/...】` 非致命，配置仍成功；如后续出现异常再排查 OpenClash Ruby 环境。
7. **`filter_aaaa_dns=1`** 是 OpenClash 的“已临时关闭 dnsmasq filter_aaaa”标志，不是过滤 AAAA。
