## 四、五条硬性注意（每一条都踩过或差点踩）

1. **只能用 `-ct` 包。** `-cu` 的 sysupgrade/fip/firstblock 全部不能混用：CT 的 `lan1` 是外置 GPY211C 2.5G PHY（`gdm4`），CU 是 4 个内建 PHY。刷错的结果是 `lan1` 起不来、默认 WAN 不对。反向同理。
2. **U-Boot 里 2.5G 口是死的。** 写完引导重启后，网线必须插 **LAN2/3/4（千兆口）** 才能打开 `http://192.168.0.1`；2.5G 口在 U-Boot 阶段没有驱动，不是砖。
3. **首启必须离线、先改 LAN。** ponwrt 默认 `192.168.31.1`（与现网主路由完全同段）；QWRT 默认 `192.168.1.1`（与光猫原厂/可能和现网撞段）。两者都要在**只连 PC** 时先改成 `192.168.88.1`，再接家里网络。
4. **factory 分区只属于这台机器。** `mtd13`（3 MiB）里的 APONCAL 光模块校准与 MT7916 WiFi EEPROM 与硬件绑定，**跨机移植无效**；刷前必须原样备份并转成 1 MiB 写回（ponwrt/QWRT 都要）。
5. **不要用联通版「一键刷入包」刷 CT。** `Fh-HG5585F-Ubi-Update-1h-V260921-*.bin` 是 CU 版（操作说明写的是联通版），CT 机型不符。需要 **CT 版同款包**，向卖家/QQ 群（1020152066）索取；拿不到就走 Telnet/串口路线。
6. **QWRT 首启 WiFi 是开放的。** 闭源驱动生成的默认配置 `encryption=none`，SSID 基于主机名；改完 LAN 后第一件事就是设 WPA2，别让开放 AP 挂着。

## 七、名词对照

| 词 | 含义 |
|---|---|
| **CT / CU** | 中国电信版 / 中国联通版。CT 多一个 2.5G 口（`lan1`），其余同板 |
| **stock2ubi** | 在**原厂系统**里以 root 运行的小工具，起 `:3333` 网页做「备份分区 + 写 U-Boot 引导」 |
| **factory 分区** | `mtd13`，3 MiB，存 PON 校准、WiFi EEPROM、MAC/SN。ponwrt/QWRT 都要 1 MiB 版 |
| **U-Boot recovery** | 刷完引导后 `http://192.168.0.1` 的网页恢复界面，负责重建 UBI、写 fip、恢复板级数据、刷系统 |
| **XMODEM** | 串口传文件协议。BL2 请求 FIP 时按 `x`，用它把 341 KB 的 fip 送进去（`脚本/xmodem-send-fip.ps1`） |
| **FIT / itb** | OpenWrt 的打包格式（kernel + DTB + rootfs 一个文件） |
| **QWRT** | 第三方重打包固件（R26.10.21，OpenWrt 25.12.3 / 内核 5.4.302 / 闭源 WiFi）；本包主目标；R26.10.21 修复了 PON OAM 兼容 |
| **ponwrt** | pbs05 的开源 Airoha 固件（v2026.10.18，内核 6.18.55 / 开源 WiFi / 带 Passwall）；本包备选 |
