## 6. QWRT CT 包（备选）FIT 与签名

```

```

metadata（JSON 282 字节 @0x2833008）：`OpenWrt` / `25.12.3` / `r7856-44e450dae4` /
`airoha/an7581` / board `fiberhome_hg5585f-ct`；supported_devices 与 ponwrt CT 相同。
尾部 **549 字节**：`0a` + `FWx0 79 2e f1 38` + `01 00 00 00` + `00 00 01 33` +
`00 00 01 64` + `00 00 00 9b` + `untrusted comment: signed by key 215087f5c3341288`
+ usign 签名 base64 + `ucert` TLV（`certtype` / `validfrom` / `expiresat` / `pubkey`）。

→ QWRT 包**带 usign/ucert 签名**（签名者标注 `Local build key`，key id `215087f5c3341288`），
ponwrt 的 CT/CU 包**不带签名**。这是"ponwrt 只能 `-F` 强刷/无签名校验"这类说法的事实依据之一。
