构建需要 CGO=1（V8 依赖）：`make build`；开发热重载用 `air` (`make dev`)；测试分为单元 (`make test-unit`)、集成 (`INTEGRATION_TESTS=true make test-integration`)、以及按层切分的 `test-service`/`test-repo`/`test-http`/`test-migrations`；OpenAPI 文档通过 `make openapi-bundle` 从 YAML 分片打包为 JSON，`make openapi-preview` 启动预览；Docker 多平台发布走 `make docker-publish`。
