使用 easimon/maximize-build-space@master Action 最大化 GitHub Actions 构建空间。配置 swap-size-mb=1024、temp-reserve-mb=100、root-reserve-mb=1024，确保 OpenWrt 大体积编译有足够的磁盘空间和交换分区。
