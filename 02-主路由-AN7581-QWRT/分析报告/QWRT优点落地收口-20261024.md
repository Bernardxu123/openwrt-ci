## 3. 终版裁决表（不搬项及理由）

| QWRT 项 | 不搬理由 |
|---|---|
| 闭源 WiFi 驱动 mt7916_ap + mt_whnat 硬件 NAT | 内核 5.4 BSP 专供，ponwrt 6.18 装不上（kmod 二进制不兼容） |
| conntrack max=65535 | 实测用量 ~1.5%，无压力 |
| UPnP SSDP/WSD notrack | 本机 UPnP 已关，收益≈0 |
| opkg 免签名源 / root 密码 password | 安全负优化 |
| HZ_250/PREEMPT_NONE 等 BSP 内核调优 | 动内核风险>收益 |
| luci-app-cpufreq（10.21 新增） | governor 建议（performance）审计仅列"可选"；主线 an7581 有 cpufreq 驱动，将来要试可 uci/手动设，不必进镜像 |
| IPTV 工具链 msd_lite/rtp2httpd/luci-app-iptv（10.21 新增） | 审计发现 PON 下行 2/3 不在 VLAN 995（疑 IPTV 组播），**等向联通确认开通 IPTV 后再加** |
| kmod-usb-net-rtl8152-vendor | 无 USB 网卡场景，按需后装 |
