# 现成方案对比：GitHub 上有没有能直接用的？

> 结论先说：**有，但没有一个能直接用在你家**。原因都在「怎么拿到信号」这一步。

---

## 1. 三个真正对口的项目

| 项目 | 星 | 平台 | 采集方式 | 能否直接用 |
|---|---|---|---|---|
| [ecoAPM/WiFiSurveyor](https://github.com/ecoAPM/WiFiSurveyor) | — | Win/Mac/Linux，单文件 exe | **跑 survey 的机器自己的 WiFi 网卡**（Linux `wlan0` / Windows 第一个网卡） | ❌ 见下 |
| [hnykda/wifi-heatmapper](https://github.com/hnykda/wifi-heatmapper) | 266 | 同上（Web UI，TypeScript，MIT） | 同上，读本机网卡 | ❌ 见下 |
| [jantman/python-wifi-survey-heatmap](https://github.com/jantman/python-wifi-survey-heatmap) | 496 | **仅 Linux**（`libnl3` 直连内核） | 本机网卡 + iperf3 带宽 | ❌ 见下 |

### 它们的共同硬限制

三个项目的采集原理**完全一样**：读「正在跑 survey 的那台机器」的无线网卡。

- 你要举着**笔记本**在屋里走一圈，每到一个点鼠标点一下户型图 → 记录该点 RSSI
- **不能用手机**：手机上没有这些程序，也没有浏览器 API 能读到 RSSI
- `python-wifi-survey-heatmap` 更严格：只认 Linux 内核直接管理的网卡，
  在 Windows 上**根本跑不起来**（作者自己在 README 里写了 "LINUX ONLY"，
  连 Docker 跑在 Windows 上也不行）

WiFiSurveyor 和 wifi-heatmapper 支持 Windows，但读的是**笔记本的网卡**。
笔记本在屋里走一圈，等于测「笔记本位置的信号」，跟你手机在同一个位置
拿到的信号并不一样（天线、握持、机身遮挡都不同）。

## 2. 那它们有什么值得抄的？

有，而且不少：

| 它们做对的 | 我们已覆盖 | 说明 |
|---|---|---|
| 户型图当底图 + 点一下记录一个点 | ✅ | 我们刚做的「点房间测信号」就是同一个交互 |
| 多点插值成热力图 | ✅ | 我们用多墙模型，比纯插值在墙边更准 |
| 2.4G / 5G 分信道出图 | ✅ | 我们两个频段都能切 |
| **iperf3 实测带宽**（不只 RSSI） | ❌ | **值得抄**：RSSI 好不代表速率好 |
| **扫周边 AP 出信道占用图** | ⚠️ 部分 | 我们只算自己两台 AP 的重叠，没扫邻居 |
| **导出 JSON 可续采** | ✅ | 我们有 `logs/survey.csv` + `geo.json` |

`python-wifi-survey-heatmap` 的 `channels24_*.png` / `channels5_*.png`
（周边 AP 信道占用条形图）是最值得借鉴的一块——你家 2.4G 到底被邻居挤成
什么样，现在只能靠猜。

## 3. 为什么我不换成它们

| 维度 | 现成项目 | 我们这套 |
|---|---|---|
| 采集设备 | 必须扛笔记本走一圈 | **路由器侧读，人在哪都行** |
| 能测几台设备 | 只有笔记本自己 | **20 台在线设备同时** |
| 是否要装东西 | 装 exe / Docker | 只要 Python 能 SSH |
| 和你家网关联 | 无 | 直接读 ONT + 小米 AP |
| 多 AP 同时观测 | ❌ 做不到 | ✅ 双 AP 差值定位 |
| 中文户型标注 | 无 | 可改名可拖框 |

关键差异是**观测点在哪**。现成项目是「设备移动、AP 不动」，
我们是「AP 不动、设备也不动，但**同时从两个 AP 看**」——
后者不需要你举着东西走路，还能顺便做定位。

## 4. 如果你还是想试现成的

最短路径（Windows，不装任何东西）：

1. 下载 [WiFiSurveyor 最新 release](https://github.com/ecoAPM/WiFiSurveyor/releases)
   的 `win-x64` 压缩包，解压
2. 双击 `WiFiSurveyor.exe`，会自动开浏览器
3. Background 选你的户型图 PNG（用我们 `plan.png` 就行）
4. Access Point 下拉选 `bernard_5G`
5. **抱着笔记本**在屋里走，每到一个位置在图上点一下
6. 走完在 AP 下拉里换 `bernard`（2.4G）再走一遍
7. 数据可存 JSON，之后还能续采

预计耗时：80 m² 户型、20 个采样点，**约 20~30 分钟**（含两次频段）。

对比我们这套：`python server.py` → 手机打开网址 → 点房间 → **每点 3 秒**。
